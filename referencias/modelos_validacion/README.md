# Modelos de Validación de Instrumentos (DEC-015)

Directorio en modo **SOLO LECTURA** para los formatos de validación de instrumentos de la UNAJMA:
- **Modelo Vigente (DEC-015):** Formato Fany 2024 con tres criterios dicotómicos (`Pertinencia`, `Relevancia`, `Claridad`: `Sí` = 1, `No` = 0), aplicable exclusivamente al Instrumento N.° 03, Modalidad A (8 ítems: `AP-01`..`AP-04` y `UP-01`..`UP-04`) según **DEC-020**.
- Referencia de contraste para auditoría documental: `CORRECION DE FORMATOS.docx`.
