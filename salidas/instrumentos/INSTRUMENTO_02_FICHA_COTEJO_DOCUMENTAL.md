### 2. REGLA OPERATIVA DE DECISIÓN: 8 CRITERIOS OBLIGATORIOS DE CONFORMIDAD

Para eliminar cualquier subjetividad en la auditoría, un registro de movimiento es clasificado de forma binaria:
* **CONFORME ($1$):** El registro cumple simultáneamente con los ocho (8) criterios obligatorios de verificación frente a la evidencia física / documento fuente ministerial.
* **NO CONFORME ($0$):** El registro presenta al menos una omisión, borrón, ilegibilidad, error de cálculo o discrepancia en cualquiera de los ocho campos obligatorios.

```
+---------------------------------------------------------------------------------------------------+
|                        LISTA DE OCHO CRITERIOS OBLIGATORIOS DE AUDITORÍA                         |
+---------------------------------------------------------------------------------------------------+
|  1. Tipo de movimiento especificado unívocamente (Entrada, Salida o Transferencia).               |
|  2. Nombre estandarizado de la vacuna / biológico según esquema nacional de inmunizaciones.       |
|  3. Número de lote registrado y coincidente con el rotulado del frasco / documento fuente.         |
|  4. Cantidad de dosis / viales exacta y coincidente con el físico / documento de despacho.        |
|  5. Fecha del movimiento completa y cronológicamente consistente (Día, Mes, Año).                |
|  6. Centro de origen o establecimiento de salud destino plenamente identificado.                  |
|  7. Nombre y cargo del personal responsable del despacho o recepción consignado.                 |
|  8. Documento de respaldo asociado (Vale oficial, PECOSA, Guía de Remisión o Acta).              |
+---------------------------------------------------------------------------------------------------+
  REGLA DE CONFORMIDAD: Si los ocho criterios son CUMPLE ⟶ CONFORME. Si cualquiera es NO CUMPLE ⟶ NO CONFORME.
```

### 4. SECCIÓN B: AUDITORÍA DE CONCORDANCIA PROGRAMADA VS. ENTREGADA ($CPE$)
